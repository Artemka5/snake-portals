# Змейка с порталами

Классическая «Змейка» в браузере с парой порталов и бонусными звёздами. Вся игра — один файл `index.html` без зависимостей.

## Как запустить

Открой `index.html` в любом современном браузере. Сервер и сборка не нужны.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Движение | Стрелки или WASD | Свайпы по полю |
| Пауза / продолжить | Пробел | Кнопка «Продолжить» |
| Начать игру | Пробел, Enter или кнопка «Играть» | Кнопка «Играть» |

## Правила

- 🍎 Яблоко — +1 очко, змейка растёт, скорость увеличивается.
- 🟣 Порталы — заходишь в один, выходишь из другого. Каждые 5 яблок порталы переезжают на новые места.
- ⭐ Звезда — +5 очков и +3 к длине. Появляется иногда и быстро исчезает (перед исчезновением мигает).
- Столкновение со стеной или с собой — конец игры.

Рекорд сохраняется в браузере (`localStorage`).
